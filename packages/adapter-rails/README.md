# @fractal/adapter-rails

Adapter para Rails: stubs, generación de código, y lógica específica de Ruby/Rails.

## Scope

Este paquete contiene **todo** el conocimiento de Rails:
- Stubs de models, controllers, migrations
- Lógica de generación de código Ruby
- Configuración específica de Rails
- Integración con ActiveRecord, ERB, Bundler
