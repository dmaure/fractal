# @fractal/adapter-laravel

Adapter para Laravel: stubs, generación de código, y lógica específica de PHP/Laravel.

## Scope

Este paquete contiene **todo** el conocimiento de Laravel:
- Stubs de modelos, controllers, migrations
- Lógica de generación de código PHP
- Configuración específica de Laravel
- Integración con Artisan, Eloquent, Blade
